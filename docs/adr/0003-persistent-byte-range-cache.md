# 持久化视频字节区间

首版在本地磁盘缓存按需读取的视频字节，已有字节从磁盘读取，缺失部分回源补齐，以支持首次播放时的随机跳转和后续播放时的区间复用。缓存跨服务重启保留，超过配置的容量上限时优先淘汰最久未使用的数据。

缓存以完整源地址为标识，签名变化后使用新的缓存条目。区间缓存仅接收与回源请求匹配的 `206 Partial Content`，源站忽略 Range 并返回 `200 OK` 时，该次代理 Range 请求失败。

缓存能够完整满足请求时直接从本地响应，期间不访问源站。缓存不设有效期，按全局 LRU 腾出容量。同一源地址、同一视频版本、同一缺失区间的并发下载共享一次回源，部分重叠的下载可以分别进行。

签名过期后，完整命中的请求仍可播放。若请求存在缺失区间且源站返回 `403`，本次请求失败。同一源地址换片后，旧缓存可继续满足完整命中，直到被淘汰或通过按完整源地址操作的运维命令清除。

需要回源补齐时，只有强 `ETag` 一致才可将新字节与旧缓存合并。发现版本变化时废弃旧区间，以新版本重新处理请求。缺少可比对的强 `ETag` 时，从一次源站响应取得本次请求所需的全部字节。

全局 LRU 以缓存区间为淘汰单位，正在读取或写入的区间等操作结束后再参与淘汰。

首版按单实例部署，进程独占本地缓存目录，缓存数据和区间索引均落盘。配置提供监听地址、缓存目录、容量上限和源站允许列表。区间完整写入并校验实际长度后才登记为可命中。写盘失败时尽量继续把源站数据交给播放器，源站在播放响应开始后中断时结束该响应，由播放器重试。

# Triage labels

Use the mapped value in a ticket’s `Status:` line when applying a triage role.

| Role | Status value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified for agent implementation. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The issue is closed without implementation. |
